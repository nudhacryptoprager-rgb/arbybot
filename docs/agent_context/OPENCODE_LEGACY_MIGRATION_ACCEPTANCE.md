# OpenCode Legacy Compatibility

This historical note is retained only to explain why `OPENCODE.md` and
`opencode.json` still exist. OpenCode is not the active ARBY3 executor.

The active agent model is:

1. GPT/ChatGPT (Codex): planning, review, priority, risk, and acceptance.
2. Cursor: bounded implementation under `CURSOR.md` and `.cursor/rules/*.mdc`.
3. Auditors: read-only second opinions under `docs/agent_context/AUDITOR_CONTRACT.md`.

For the active readiness checklist, use
`docs/agent_context/CURSOR_EXECUTOR_ACCEPTANCE.md`.

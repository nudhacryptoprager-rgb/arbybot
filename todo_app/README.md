# Todo App

A minimal client-side Todo app that persists to `localStorage`.

Files:
- index.html — main page
- app.js — JavaScript logic (add/edit/delete/complete, localStorage)
- styles.css — small stylesheet

To run:
1. Open `todo_app/index.html` in your browser (double-click or use `file://`).

No server required.

Notes:
- Edit tasks inline (click text to edit, then blur to save).
- Tasks are saved to localStorage for persistence.
